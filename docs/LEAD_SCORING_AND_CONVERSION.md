# Lead Scoring and Conversion Metrics

This document explains the dashboard values shown in the Marketing Agent activity panel.

## Lead Score

Lead score is generated by the Lead Capture Agent when a visitor submits a landing page form.

Implementation:

```text
app/agents/lead_capture.py
```

Every lead starts with a base score of `35`.

The agent then adds:

| Rule | Score Added |
| --- | ---: |
| Company name is provided | 20 |
| Message is present and longer than 40 characters | 25 |
| Email domain is not `gmail.com`, `yahoo.com`, or `hotmail.com` | 20 |

The final score is capped at `100`.

Formula:

```text
score = min(35 + company_bonus + message_bonus + business_email_bonus, 100)
```

Examples:

| Lead Data | Score |
| --- | ---: |
| Name and free email only | 35 |
| Company + free email | 55 |
| Company + business email | 75 |
| Company + long message + business email | 100 |

## Lead Status

The same agent assigns lead status after scoring.

```text
score >= 70 -> qualified
score < 70  -> new
```

That is why leads with scores like `75` and `100` appear as `qualified` in the dashboard.

## Visits

Visits are counted when a published landing page is opened through:

```text
/p/{slug}
```

Implementation:

```text
app/api/routes.py
```

When the page is found and rendered, the app increments:

```text
landing_pages.visits
```

## Conversions

Conversions are counted when a visitor submits the lead form for a landing page.

When the Lead Capture Agent receives a lead with `page_id`, it increments:

```text
landing_pages.conversions
```

The same request also creates a row in:

```text
leads
```

## Dashboard Conversion %

The dashboard conversion rate is calculated across all landing pages.

Implementation:

```text
GET /api/dashboard
```

Formula:

```text
conversion_rate = round((sum(landing_pages.conversions) / sum(landing_pages.visits)) * 100, 2)
```

If there are no visits yet, conversion is shown as `0`.

Example from the dashboard:

```text
Visits = 3
Conversions = 3
Conversion % = 3 / 3 * 100 = 100%
```

## Important Interpretation

The current score and conversion logic is intentionally deterministic and transparent. It is suitable for a production prototype because every value can be audited.

Future improvements can add:

- CRM enrichment.
- Company-size scoring.
- Job-title scoring.
- Email deliverability checks.
- Duplicate lead handling.
- Weighted attribution by campaign and page.
- Time-windowed conversion rates.
