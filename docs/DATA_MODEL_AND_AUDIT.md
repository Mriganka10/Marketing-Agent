# Data Model and Audit

## Database

The app uses SQLAlchemy ORM models in `app/models/entities.py`.

Default local database:

```text
data/marketing_agent.db
```

Production recommendation:

```text
RDS Postgres
```

## Main Tables

### `business_profiles`

Stores company context.

Important fields:

- `name`
- `website`
- `industry`
- `audience`
- `value_proposition`
- `offers`
- `competitors`
- `tone`

### `campaigns`

Stores campaign goal and execution status.

Important fields:

- `business_id`
- `name`
- `goal`
- `target_region`
- `status`

### `demand_signals`

Stores keyword and buyer-intent signals generated by the Research Agent.

Important fields:

- `campaign_id`
- `keyword`
- `intent`
- `region`
- `priority_score`
- `rationale`

### `landing_pages`

Stores generated page content.

Important fields:

- `campaign_id`
- `slug`
- `title`
- `hero`
- `sections`
- `cta`
- `seo`
- `status`
- `visits`
- `conversions`

### `leads`

Stores captured leads.

Important fields:

- `campaign_id`
- `page_id`
- `name`
- `email`
- `company`
- `message`
- `score`
- `status`
- `source`

### `refresh_recommendations`

Stores Analytics/Refresh Agent recommendations.

Important fields:

- `campaign_id`
- `page_id`
- `severity`
- `recommendation`
- `expected_impact`
- `status`

### `audit_events`

Stores audit records.

Important fields:

- `actor`
- `action`
- `entity_type`
- `entity_id`
- `event_metadata`
- `created_at`

## Audit Events

Audit events are written through:

```text
app/core/audit.py
```

Current audited actions:

- Business profile created.
- Campaign created.
- Demand signals generated.
- Landing pages created.
- Lead captured.
- Refresh recommendations created.

## Audit API

```http
GET /api/audit
```

Returns the 100 most recent audit events.

## Data Retention

For production:

- Keep audit records for at least 90 days.
- Export audit snapshots to S3 if compliance or owner reporting is needed.
- Back up SQLite for local development; production relies on RDS automated backups and snapshots.
- Prefer RDS automated backups for production.
