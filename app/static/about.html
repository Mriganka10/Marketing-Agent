Google Ads API integration

Purpose-built for reporting, validation, and approval-controlled campaign operations.

Google Ads API access connects approved campaign planning in Marketing Agent with the advertising accounts that Kairoz has been authorized to support. It reduces manual copying, validates campaign structures before submission, and keeps paid activity aligned with the client’s approved landing pages and objectives.

Campaign reporting

Reads campaign name, status, impressions, clicks, cost, and conversion metrics for transparent performance reporting.

Plan validation

Uses Google Ads validation mode to check budgets, Search campaigns, ad groups, keywords, and responsive search ads before a live operation.

Approved creation

Creates approved campaign components in a paused state so no advertising spend begins automatically.

Controlled updates

Allows authorized operators to submit approved campaign-name, status, and daily-budget changes with an auditable workflow.

Google Ads data is accessed only for client accounts that have expressly authorized Kairoz Corporation and are connected through the relevant Google Ads account or manager-account relationship.

Campaign and data safeguards

Designed to support accountable operators.

No autonomous spend activation

New Google Ads campaigns and related assets are created paused by default. The platform does not independently activate advertising spend.

No cross-client data sharing

Business records, pages, leads, reports, and campaign plans are partitioned by client engagement and used only for the authorized service.

No resale of Google Ads data

Google Ads information is used to deliver reporting and campaign-management services to the account owner; it is not sold or used for unrelated advertising.

Explicit live-push approval

Validation is separate from publishing. A live API operation requires an explicit authorized action and is recorded in the application audit trail.

Restricted credentials

API credentials and access tokens are maintained in restricted production secret storage and are not exposed in the portal interface.

Clear source provenance

Google Ads, GA4, Search Console, application events, and application leads remain separately labelled to prevent misleading reporting.
